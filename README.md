# HiGLUE
Joint generative modeling of single-cell Hi-C with other single-cell modalities via Graph-Linked Unified Embedding (GLUE)

HiGLUE depends on the following packages: 

* `SCORE`: https://github.com/JinLabBioinfo/SCORE.git

* `scglue`: https://scglue.readthedocs.io/en/latest/ (note that HiGLUE currently needs a custom fork of `scglue`)

To install these packages for HiGLUE, you can run the following:

`pip install git+https://github.com/JinLabBioinfo/SCORE.git`

`pip install git+https://github.com/dylan-plummer/GLUE.git`


After installing the above packages, you need to generate the 3 input files for training HiGLUE:

* scRNA `scanpy` object

* scHi-C `scanpy` object

* `networkx` guidance graph

These can be generated by running the `preprocess_data.py` script:

```
python preprocess_data.py --rna_file human_islet.h5ad \
						  --gtf hg19_genes.gtf \
						  --dset islet \
			  			  --scool islet_10kb.scool \
						  --reference islet_ref \
						  --resolution 10kb
```

* `--rna_file` points to a `scanpy` object with gene features and at least a `celltype` observation annotation (`rna.obs['celltype']`)

* `--gtf` points to a GTF file to map gene names to genomic coordinates. It should have a `gene_symbol` column

The remaining arguments are identical to those of the `scloop` package. The following are required for HiGLUE preprocessing:

* `--dset/--dataset_name`

* `--scool`

* `--reference`

* `--resolution`

After running the preprocessing script, you should have an output directory `<dataset_name>_data` containing the following folders:

* rna

* hic

* graphs

These folders contain the three input files needed for the next step of training a HiGLUE model.
